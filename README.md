# Diadem Route Helper

ディアデムなどの採集で使う、完全手動のDalamudルート案内プラグインです。

## 導入用URL

Dalamudのカスタムプラグインリポジトリに、次のURLを追加します。

`https://raw.githubusercontent.com/nananachch/test/main/repo/pluginmaster.json`

## 機能

- 現在地をウェイポイントとして登録
- 次・前の地点へ手動切替
- 方角と水平距離をオーバーレイ表示
- 素材のセッション取得数と時給を集計

自動移動、自動マウント、自動ターゲット、自動採取、自動ルート切替、ワープ、速度変更、ゲームへの操作入力は一切行いません。

## コマンド

- `/dnav` 画面の開閉
- `/dnav next` 次の地点
- `/dnav prev` 前の地点
- `/dnav add` 現在地を追加

## 注意

XIVLauncher / Dalamudを含む第三者ツールは、FFXIVで公式に許可されたものではありません。利用判断は自分で行ってください。
