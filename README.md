# 採取補助

FFXIV / Dalamud向けの手動採集ナビゲーション支援プラグインです。

## 主な機能

- 名称を問わず、現在読み込まれている採集地点から最寄りを自動案内
- キャラクター位置と同じ高さを基準にした画面上の矢印
- ターゲット中または最寄りの採集地点をルートへ登録
- 登録順に周回し、到着時に次の地点へ案内先を自動切り替え
- 装備耐久が設定値を下回ったときに通知
- 素材の取得数と時給を集計

自動移動、自動ターゲット、自動採取、キー入力は行いません。

## コマンド

- `/dnav`
- `/dnav next`
- `/dnav prev`
- `/dnav add`
- `/dnav addtarget`
- `/dnav addnearest`
